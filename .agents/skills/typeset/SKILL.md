# Typeset

Use when refining typography for financial dashboards.

## Protocol

1. Use `font-display` for headings, `font-body` for prose, `font-mono-data` for numbers
2. Keep a clear type scale (xs labels → lg section titles)
3. Ensure financial figures align and scan easily
